# KAOS Trading Bot 1.5.2

Restores the missing user-facing multi-chart trading control requested for the Dashboard.

- Directly below START KAOS / STOP: “How many charts do you want to trade?” with 1–4 choices.
- The choice is saved.
- The Charts page shows exactly that many chart workspaces.
- 1 = one full-width chart.
- 2 = two charts.
- 3 = three charts in the 2-column workspace.
- 4 = full 2×2 workspace.
- Each visible chart retains its independent strategy selector.
- Start configuration now includes only the number of enabled chart slots chosen by the user.
- OPEN CHARTS jumps directly to the selected multi-chart workspace.

B32.24 execution rules are unchanged.
