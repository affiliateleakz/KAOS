# KAOS Trading Bot 1.6.13

- Removed Mid view. KAOS now has Mini and Max only.
- Existing saved Mid preference migrates to Max automatically.
- Max no longer opens KAOS as a normal Chrome tab. It resizes the dedicated KAOS app window.
- When Max is selected, Pocket Option is explicitly kept as the active/selected tab in its Chrome window and marked non-discardable. KAOS then returns focus to its own app window without changing Chrome's selected Pocket Option tab.
